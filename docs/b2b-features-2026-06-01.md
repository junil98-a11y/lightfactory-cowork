## 2. 기능별 상세

### 2-1. 다중 배송지(주소록)
- **데이터**: `currentUser.addresses[]` (`{id,label,recipient,phone,zip,addr1,addr2,isDefault}`), localStorage 영속.
- **마이페이지 › 주소록 탭**: 추가/수정/삭제/기본배송지 지정. 카카오 우편번호 재사용(`searchAddrFor`).
- **주문서**: 저장된 배송지 드롭다운 + "새 주소" 버튼. 기본 배송지 자동 선택·자동 채움.

### 2-2. 재구매·발주서
- **마이페이지 › 재구매·발주 탭** + 사업자 GNB 메뉴.
- **재주문**: 주문내역 카드의 `재주문` → 품절/비활성 제외하고 장바구니 채움.
- **즐겨찾기**: 상품 상세의 ☆ 토글(`currentUser.favorites[]`). 즐겨찾기 목록에서 바로 담기.
- **CSV 발주서**: `SKU,수량` 업로드 → SKU 매칭하여 장바구니 자동 채움. 양식 다운로드 제공.

### 2-3. 거래처별 단가 커스터마이즈
- **단가 우선순위**: 거래처별 customRates → 품목군 `PRICE_POLICY` → 전사 일괄 `R[]`.
- `sp(base, prod)` / `unitPrice(prod)` / `effRate(prod)` 공용 함수로 그리드·상세·장바구니·체크아웃 단가 일원화.
- **관리자 › 회원목록 › 사업자 › "거래처 단가"**: 품목별 할인율(%) 매트릭스 편집. 이메일 기준 맵(`lf_custom_rates`) + 동일 이메일 로그인 유저에 즉시 반영.

### 2-4. RMA(취소·반품·교환)
- **데이터**: `RMAS[]` (상태흐름 requested→approved→done/rejected), localStorage 영속.
- **고객**: 주문내역 카드에서 발송 전=주문취소, 발송 후=반품/교환 요청. 사유+상세 입력.
- **관리자 › 취소·반품·교환**: 필터·승인·거절·완료. **승인 시 재고 자동 복원** + 주문상태 '취소' 전환(취소/반품). 환불은 PG 부분취소 연동 필요(데모는 표기).

### 2-5. 단가정책·마진보호·도매전용관 (영업)
- `PRICE_POLICY`: 실링팬·IoT 조명 T1 15/T2 10/T3 8%, 마그네틱 T1 20/T2 15/T3 10%.
- 도매 전용관: 사업자/관리자 한정, `biz:true` 품목만 노출.
- 36개 전 품목에 한 줄 스펙 상세설명 자동 주입(관리자 수정본은 보존).

### 2-6. 디자인
- 체크아웃 3-step 스텝퍼(배송지→결제수단→완료, 완료 시 3단계 강조).
- `--hint` `#A8A7A2`→`#767570`(대비 ≈4.5:1), 상품 본문 텍스트 11px.
- toast `role="status" aria-live="polite"`.
- 결제 영역 SSL·토스 안전결제 배지, 상품카드/상세 "내 단가 절약 ₩".

## 3. 데모(프론트 단독) 한계
- localStorage 기반이라 기기 간 동기화·동시성 보장 없음 → 백엔드 이관 시 해소.
- 카카오 우편번호 SDK는 온라인에서만 동작(오프라인 시 직접 입력 폴백).
- RMA 환불, 교환 재배송은 표기만(실제 PG/물류 연동은 백엔드 영역).
- 거래처 단가 매트릭스는 데모 `BIZ_MEMBERS`(b1~b4) 기준. 실제 로그인 계정과는 이메일로 연결.

## 4. ✅ 검증 체크리스트 (사용자용 일괄 확인)

`shop/index.html`을 브라우저로 열고 순서대로 확인하세요. (관리자 진입: 로고 더블클릭 → 관리자 로그인)

> 사업자 단가 확인이 필요하면, 개발자 콘솔에서 로그인 후 데모로 `setRole('t1')`을 쓰거나 사업자 가입→관리자 승인 절차를 거칩니다. (운영 차단 가드는 localhost에서 해제됨)

### A. 다중 배송지
- [ ] 로그인 → 마이페이지 → **주소록** 탭 → "새 주소 추가" → 카카오 주소검색 → 저장
- [ ] 두 번째 주소 추가 후 "기본으로" 지정 → 기본 배지 이동 확인
- [ ] 장바구니 → 주문서 진입 시 **저장된 배송지 드롭다운**에 기본 주소 자동 선택·자동 채움
- [ ] 주문서에서 "새 주소" 버튼 → 추가 후 드롭다운 갱신

### B. 재구매·발주
- [ ] 상품 상세에서 ☆ 버튼 → 즐겨찾기 담김(별 채워짐) → 마이페이지 재구매·발주 탭에 노출
- [ ] 즐겨찾기 항목 "담기" → 장바구니 반영
- [ ] 주문내역 카드 "재주문" → 장바구니 채워지고 장바구니 화면 이동
- [ ] 재구매·발주 탭 → "양식 다운로드" → 받은 CSV 업로드 → "N개 품목 담김" 토스트

### C. 거래처별 단가 (관리자)
- [ ] 관리자 → 회원 목록 → 사업자 탭 → 한 업체의 **"거래처 단가"** → 특정 품목 할인율 입력 → 적용가 즉시 계산 → 저장 → 버튼에 (건수) 표시
- [ ] (해당 이메일로 로그인 시) 상품 단가가 "맞춤가"로 적용되는지

### D. RMA
- [ ] 주문내역 카드에서 발송 전 주문 "주문취소" / 배송완료 주문 "반품"·"교환" → 사유 선택 → 접수
- [ ] 관리자 → **취소·반품·교환** → 사이드바 배지 카운트 → "승인" → 해당 상품 **재고 증가**(상품 목록/재고에서 확인) + 주문상태 '취소'

### E. 디자인/정책
- [ ] 주문서 상단 **3-step 스텝퍼**, 결제 완료 시 3단계 활성
- [ ] 결제 버튼 아래 **SSL·토스 안전결제 배지**
- [ ] 사업자 로그인 시 상품카드/상세에 **"내 단가 절약 ₩"** 표시
- [ ] 사업자 GNB 메뉴 → **도매 전용관** → biz 품목만 노출
- [ ] 실링팬/IoT 품목의 사업자 할인율이 30%가 아니라 **15/10/8%**로 적용
- [ ] 상품 상세 "상세 설명" 탭에 품목 설명 노출(36종)
