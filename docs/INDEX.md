## 🗺 로드맵

### High Priority (B2B 핵심 누락 기능)

#### 1. 후불결제 · 여신한도
- **이유**: T1 시공업체 핵심 결제수단, 현재 토스 단건만
- **작업**:
  - ORDERS에 `paymentTerm`('immediate'/'credit') 필드 추가
  - 거래처별 여신한도(`creditLimit`) + 누적 미수금(`creditUsed`) 관리
  - 관리자 메뉴: 거래처별 여신 설정
  - 마이페이지: 미수금 현황 · 입금 통보
- **영향 파일**: `shop/index.html` (USERS·ORDERS 스키마 확장, 관리자 메뉴 추가)

#### 2. 다중 배송지 (현장별)
- **이유**: 인테리어 시공업체는 현장 직배송이 표준
- **작업**:
  - USERS에 `addresses[]` 배열 (라벨·우편번호·주소·메모)
  - 주문서: 배송지 선택 드롭다운 + "새 주소 추가" 버튼
  - 마이페이지: 주소록 탭

#### 3. 재구매 · 발주서 업로드
- **이유**: 시공업체 SKU 80%가 반복 발주
- **작업**:
  - 마이페이지 주문내역에 "재주문" 버튼 (cart 즉시 채움)
  - 즐겨찾기 SKU 리스트
  - CSV/엑셀 발주서 업로드 → cart 자동 채움

#### 4. 거래처별 단가 커스터마이즈
- **이유**: 현재 R 일괄 적용, 대형거래처 협상가 불가
- **작업**:
  - USERS.bizInfo에 `customRates: {prodId: discountRate}` 추가
  - 관리자 회원관리에서 거래처별 단가 매트릭스 편집
  - `sp(base, userId)` 로 시그니처 확장

#### 5. 주문 취소 · 반품 · 교환 RMA
- **이유**: 현재 상태에 '취소'만, 환불/재고복원 로직 없음
- **작업**:
  - RMA 모델 (사유·이미지·상태 흐름)
  - 마이페이지 취소/반품 요청 폼
  - 관리자 RMA 처리 메뉴 + 재고 복원

### Mid Priority (운영 보강)

#### 6. 백엔드 이관
- **현재**: `backend/lightfactory-v2-naver.tar.gz` 압축만 존재
- **작업**: 압축해제 → Next.js API → 인증/회원/주문/결제 confirm 이관
- **선결 효과**: 결제 금액 변조 차단, 다중기기 동기화, 평문→bcrypt

#### 7. 단일 HTML 청크 분리
- **현재**: 423KB 단일 HTML 동기 로드
- **작업**: Vite/ESBuild로 admin/shop 분리, 초기 로드 200KB 미만 목표

#### 8. 결제 confirm 서버 검증
- **현재**: 클라이언트 측 `final` 변수 그대로 토스로 전달
- **작업**: 서버에서 orderId → DB 금액 대조 후 토스 confirm 호출

### Design Sprint (디자인팀장 요청)

- 체크아웃 모달 3-step 스텝퍼 (견적 모달 `.qm-step-bar` 이식)
- 모바일 하단탭바 실제 구현 또는 스펙 폐기 결정
- `.toast`에 `role="status" aria-live="polite"` 추가
- `--hint #A8A7A2` 대비비 4.5:1 충족 톤으로 상향
- 9~10.5px 폰트 11px↑ 일괄 상향
- 결제 영역 SSL·토스 안전결제 배지 추가
- 상품카드/상세에 "내 단가 대비 절약 ₩" 강조 (B2B 전환율)

### Sales Sprint (영업팀장 권장)

- 품목군별 단가 정책 데이터 모델 확장 (현재 R 일괄)
