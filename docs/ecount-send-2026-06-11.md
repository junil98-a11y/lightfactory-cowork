# 이카운트 ERP 판매 자동 등록 (전송대기 → 전송) — 2026-06-11

대상: `shop/index.html` 관리자 주문 관리

## 요청
주문 관리에서 이카운트 `전송대기` 상태인 주문을, 관리자가 확인 후 「이카운트로 전송」 버튼을 누르면 이카운트 판매(매출) 페이지에 자동 등록.

## 변경 전
- 주문 상세(odm) 이카운트 섹션은 `전송실패`일 때만 「재전송」 버튼 노출. `전송대기`는 상태 텍스트만 표시, 전송 수단 없음.
- `retryEcount()`는 상태만 `전송완료`로 바꿈(전표/로그 없음).

## 변경 후
- **신규 `sendToEcount(orderId)`**: 이카운트 판매입력(매출전표, `SaveSale`) payload 구성(거래처·품목 SKU/수량/단가·공급가/부가세/합계) → 등록 → `ecount='전송완료'`, **판매전표번호 `EC-YYYYMMDD-XXXXX`** 발번 + `ecountSentAt` 기록 → `saveOrders()` 영속화 → 모달·목록 갱신.
  - `lf_ecount_key` 가 있으면 실 OAPI 호출 자리(현재 데모는 시뮬레이션), 없으면 전표번호 시뮬 발번.
  - 중복 전송 방지(`_ecountSending`), 전송완료/취소 주문 가드.
- **주문 상세 이카운트 섹션**: `전송대기` → 「이카운트로 전송」(primary) + 안내문 / `전송완료` → 판매전표번호·전송일시 표시 / `전송실패` → 재전송.
- **주문 목록 테이블**: `전송대기` 배지를 amber(b-warn)로 변경 + 행에 빠른 「전송」 버튼(`event.stopPropagation`).
- `retryEcount()`는 `sendToEcount()` 호출로 호환 유지.

## 검증 (Playwright + 시스템 Chrome) — 9건
- 전송대기: 상세 「이카운트로 전송」 + 목록 빠른 전송 버튼 노출 ✅
- 전송 후: `전송완료`, 전표번호 `EC-YYYYMMDD-XXXXX` 발번, 전송일시 기록, 상세 전표 표시, localStorage 영속화, 목록 반영 ✅
- 전송완료 주문 재전송 차단(전표 불변) ✅

## 비고
- 데모는 시뮬레이션 발번. 실 연동 시 `sendToEcount` 내 setTimeout 블록을 이카운트 OAPI `fetch` 로 교체하고 응답 전표번호를 사용.
