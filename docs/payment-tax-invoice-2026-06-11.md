# 결제수단 개인/사업자 구분 + 은행결제 세금계산서 발행 개정

작성일: 2026-06-11 · 대상: `shop/index.html`

## 요청 요약
1. 결제방법을 **개인 = 카드결제·은행이체**, **사업자 = 카드결제·은행결제** 로 구분
2. **은행결제 시** 등록된 사업자 정보로 세금계산서 발행 요청 가능
3. 세금계산서 발행 대상을 **제3자(다른 업체)** 로 변경 가능
4. 발행 정보를 **구매 내역(주문내역)** 에서 확인 가능

## 5팀장 검토
- **기획**: 카드결제는 카드매출전표가 증빙 → 세금계산서 신청은 **은행결제일 때만** 노출(B2B 회계 실무 정합).
- **개발**: 실제 결제 함수는 `submitOrderWithToss`(DOMContentLoaded에서 버튼 onclick 교체). 결제수단 옵션은 `openCheckout()`에서 role 기준 동적 생성, 노출 토글은 `onPayMethodChange()`로 일원화.
- **품질**: 제3자 발행 시 사업자번호 입력 잠금 해제 + 형식검증(`requestTaxInvoice`) 유지. 본인 발행일 때만 회사정보 저장(제3자 정보 오염 방지).
- **디자인/영업**: 주문내역 카드에 발행 상태 배지 + 대상 업체명(제3자 표기) + 발행 완료 시 "보기" 버튼.

## 변경 내역 (코드)
| # | 위치 | 내용 |
|---|------|------|
| 1 | 결제수단 `select#co-pay-method` | 정적 4종(카드/카카오/토스/무통장) → role 동적 2종. `onchange="onPayMethodChange()"` + 입금안내 박스(`#co-bank-guide`) 추가 |
| 2 | 세금계산서 폼 `#co-tax-form` | 상단에 **발행 대상 라디오**(`co-tax-target`: self/third) 추가. 저장 체크박스에 `#co-tax-save-row` 부여(제3자 시 숨김) |
| 3 | `openCheckout()` | 결제수단 옵션 동적 생성(개인 `[카드결제,은행이체]` / 사업자 `[카드결제,은행결제]`). 세금 폼 기본 대상 self 세팅 후 `onPayMethodChange()` 동기화 |
| 4 | **신규** `onPayMethodChange()` | 은행 계열 → 입금안내 노출. **사업자+은행결제일 때만** 세금 섹션 노출, 그 외 숨김+신청 해제 |
| 5 | **신규** `setCoTaxTarget(target)` | self=등록 사업자 정보로 채움+사업자번호 잠금 / third=전 필드 비우고 직접 입력(사업자번호 잠금 해제), 저장 비활성 |
| 6 | `submitOrderWithToss()` | 신청 조건을 `isBiz && payMethod==='은행결제'`로 강화. `recipient.thirdParty` 플래그 저장. **본인 발행일 때만** `saveMyBizExtraInfo()` |
| 7 | `renderMyOrders()` | 주문 카드에 세금계산서 발행 상태/대상 행 + `openTaxPreview()` "보기" 버튼 추가 |

## 동작 흐름
1. 사업자 로그인 → 주문서: 결제수단 = `카드결제`/`은행결제`. 기본 카드결제 → 세금 섹션 숨김.
2. `은행결제` 선택 → 입금안내 + 세금계산서 섹션 노출.
3. `세금계산서 신청` 체크 → 폼 표시. 기본 **등록된 사업자 정보**로 자동 채움(사업자번호 잠금).
4. **제3자** 라디오 선택 → 필드 비워짐·사업자번호 입력 가능 → 다른 업체 정보로 발행 신청.
5. 결제 완료 시 신청 생성(상태 `발행 대기`) → 관리자 발행 처리 → 상태 `발행 완료`.
6. 마이페이지 → 주문내역 카드에서 발행 상태·대상 업체·보기 버튼 확인.

## 비고 / 후속
- 카드결제 미연동(토스 키 없을 시 시뮬레이션)·은행결제는 계좌 안내 문구만 — 실제 입금 매칭은 백엔드 이관 단계 과제.
- 세금계산서 필드 미입력 시 주문은 완료되고 신청만 실패 토스트(기존 soft-fail 패턴 유지). 추후 결제 전 하드 검증 검토 가능.
- 마이페이지 세금계산서 탭의 사후 신청 경로는 기존대로 유지(제3자 옵션은 주문서 경로에만 적용).
- 데이터는 브라우저 localStorage 기준(공용 DB 아님).
