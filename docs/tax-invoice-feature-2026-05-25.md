# 라이트팩토리 — B2B 세금계산서 기능 구현

**적용일**: 2026-05-25
**대상**: `shop/index.html` (단일 HTML 추가 구현)
**구현 수준**: 데모 — 관리자 클릭 한 번으로 발행완료, 미리보기/인쇄(PDF 저장) 지원

---

## 1. 사용자 흐름

### 사업자(T1/T2/T3) 관점
1. **마이페이지 → 세금계산서 탭** (사업자만 노출)
   - 공급받는자 회사 정보 등록 (상호명·대표자·주소·업태·종목·세금계산서 이메일)
   - 한 번 저장하면 다음 주문 시 자동 채움
2. **주문서 화면** — 결제 수단 아래에 "세금계산서 신청" 체크박스
   - 체크 시 회사 정보 폼이 펼쳐지며 마이페이지에 저장된 값으로 자동 채움 (수정 가능)
   - "이 정보를 회사 정보로 저장" 옵션 (기본 ON)
3. **결제 완료** → 세금계산서가 "발행 대기" 상태로 자동 신청됨
4. **마이페이지 신청 이력**에서 상태(대기/발행/취소) 확인 + 미리보기 + 취소
5. **사후 신청** — 발행 안 된 과거 주문도 마이페이지에서 신청 가능

### 관리자 관점
1. 사이드바 → 운영 → **세금계산서** (대기 건수 빨간 배지)
2. 공급자(라이트팩토리) 정보 카드 + 수정 모달
3. 상태/검색 필터, 통계(대기·완료·취소·총 부가세액)
4. 행별 액션: **미리보기 / 발행 / 취소**
5. 발행 처리 시 콘솔에 이메일 발송 시뮬레이션 로그 (실제 e-Tax API 자리)

## 2. 데이터 레이어

### 신규 localStorage 키
- `lf_tax_invoices` — 신청·발행 이력 배열 (`TAX_INVOICES`)
- `lf_tax_supplier` — 공급자(라이트팩토리) 정보 (`TAX_SUPPLIER`)

### 세금계산서 객체 스키마
```js
{
  id:           'TI-202605-001',      // 자동 채번
  orderId:      'LF-20260525-12345',
  userId:       'u_...',
  status:       'requested' | 'issued' | 'canceled',
  requestedAt:  '2026. 5. 25. 오후 ...',
  issuedAt:     null | '...',
  canceledAt:   null | '...',
  issuedBy:     null | 'admin@...',
  supplier:     { bno, name, ceo, addr, bizType, bizItem, taxEmail },  // 스냅샷
  recipient:    { bno, name, ceo, addr, bizType, bizItem, taxEmail },  // 스냅샷
  items:        [...]                                                  // 품목 스냅샷 (단가 변경 방어)
  supplyAmt, vatAmt, totalAmt,
  note, autoCreated
}
```

### 핵심 함수
- `requestTaxInvoice(orderId, recipientInfo, opts)` — 신청 생성 + 중복 차단 + 사업자번호 검증
- `issueTaxInvoice(invId, adminId)` — 관리자 발행 처리
- `cancelTaxInvoice(invId)` — 취소 (발행 완료 후 차단)
- `saveMyBizExtraInfo(extra)` — 사용자 회사 정보 저장 (재사용)
- `openTaxPreview(invId)` — 미리보기 모달 렌더

## 3. 4팀장 요구사항 반영

### 기획팀장
- ✅ B2B 핵심 누락 기능 충족 (4팀장 리뷰 High 우선순위)
- ✅ 공급가/부가세 분리 — 이미 P0 패치 시 ORDERS에 `supplyAmt`/`vatAmt` 추가됨
- ✅ 견적서 → 주문 → 세금계산서로 흐름 자연스럽게 연결
- ✅ 마이페이지 사후 신청 — 결제 후 깜빡한 경우 대응

### 개발팀장
- ✅ 발행 시점 공급자/공급받는자 정보 **스냅샷 저장** (이후 회사 정보 수정해도 발행본 보존)
- ✅ 품목 단가도 스냅샷 (단가 변경 방어)
- ✅ localStorage 영속화 + `loadAllFromStorage`에서 복원
- ✅ XSS — 미리보기 모달의 모든 사용자 입력 영역에 `escapeHTML` 적용
- ✅ 사이드바 배지 — 대기 건수 실시간 반영, 0건이면 자동 숨김

### 품질팀장
- ✅ **사업자번호 형식 검증** (`/^\d{3}-?\d{2}-?\d{5}$/`)
- ✅ **동일 주문 중복 신청 차단** — 취소 건은 재신청 가능
- ✅ **발행 완료 후 취소 불가** — "수정세금계산서 발행 필요" 안내
- ✅ 신청 취소 시 주문의 `taxInvoiceRequested = false` → 재신청 허용
- ✅ 발행/취소 시 confirm 다이얼로그
- ✅ 필수 필드 검증 (상호명·대표자·이메일·주소)

### 디자인팀장
- ✅ **국세청 양식 모방** — 다크 그리드, 공급자/공급받는자 분리, 합계 4분할
- ✅ **인쇄 전용 CSS** (`@media print`) — A4 14mm 여백, 모달/버튼 숨김
- ✅ **PDF 저장** — 브라우저 인쇄 → "PDF로 저장" 옵션
- ✅ **모바일 반응형** (`@media (max-width:540px)`) — 공급자/받는자 1열로 전환, 합계 2분할
- ✅ **발행완료 워터마크** (반투명 "발 행 완 료" 회전 텍스트)
- ✅ 상태 배지 — 색상 일관성 (대기=앰버, 완료=그린, 취소=그레이)
- ✅ 심플한 디자인 유지 (CLAUDE.md 요구) — 추가 라이브러리 없이 인라인 CSS

## 4. 확인 방법

1. `shop/index.html`을 브라우저로 열기
2. **사업자 흐름 테스트**:
   - 로그인 → DEV 패널에서 T1 역할 선택 (localhost)
   - 상품 → 장바구니 → 주문하기
   - 결제수단 아래 "세금계산서 신청" 체크 → 회사 정보 입력 → 결제
   - 결제 완료 화면에 신청번호 표시
   - 마이페이지 → 세금계산서 탭 → 미리보기/인쇄 시도
3. **관리자 흐름 테스트**:
   - 관리자 로그인 → 사이드바 운영 → 세금계산서
   - 대기 건 클릭 → 발행 처리 / 취소 시도
   - 공급자 정보 수정 모달
4. **인쇄 검증**:
   - 미리보기 모달에서 "인쇄/PDF 저장" 클릭
   - 브라우저 인쇄 미리보기에서 A4 양식 확인 → "PDF로 저장" 선택
